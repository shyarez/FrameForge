**Reading the table**

- *Full regeneration* is generating a brand-new story from the new data. It is similar in speed, but it discards every manual edit; the update keeps them while refreshing only data-bound content.
- *Claims match fresh analysis* compares every data-bound text after the update with a fresh analysis of the new data.
- *Claims reproduce* re-runs every stored calculation against the dataset version it records.
- For the breaking change, affected scenes are marked stale with reasons instead of guessing, and their last good values are kept.

## 3. Limits

- Scene **content** updates selectively. **Video rendering does not**: every export re-renders all frames (no segment caching). Export speed is recorded per project in the editor's Evaluation panel.
- Narration uses deterministic templates; no LLM is involved, so no statistic can come from a model.
